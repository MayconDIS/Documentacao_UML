# Roadmap: Nex_TI

## Milestone 1: MVP - Fundação (Current)
- **Phase 1: Autenticação e Perfis (US01, US02, US03)**
  - Implementar Login, JWT via HttpOnly cookies, Registration (BCrypt) e permissões Admin.
- **Phase 2: Acessibilidade Base (US15)**
  - Estruturar a UI principal com CSS Grid, WAI-ARIA e Web design responsivo.

## Milestone 2: Motor de Aprendizado (SM-2)
- **Phase 3: Flashcards Core (US05, US07)**
  - CRUD para flashcards globais (Tutor) e pessoais (Aluno).
- **Phase 4: Estudo e Nivelamento (US04, US06)**
  - Implementar algoritmo SM-2 (easiness factor, interval, repetitions) e teste de classificação.

## Milestone 3: Gamificação e Suporte Acadêmico
- **Phase 5: Gamificação (US08, US09, US10)**
  - XP, Moedas, Dashboard central, Desbloqueio de trilhas.
- **Phase 6: Suporte e Simulação (US11, US12, US13, US14)**
  - Integração com LLM, Tickets para Tutor, Relatórios de desempenho, Simulado ENADE.

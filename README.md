# Nex_TI - Projeto PIM III (Documentação UML)

Bem-vindo ao repositório do projeto **Nex_TI**. Este repositório contém a documentação teórica, a modelagem UML e os esqueletos de código-fonte referentes à plataforma educacional gamificada baseada no algoritmo SM-2.

## Estrutura de Pastas

Para facilitar a avaliação acadêmica, o repositório foi organizado nas seguintes sessões:

*   **`01_Documentacao_Teorica/`**
    *   Contém os arquivos textuais de engenharia de software e métodos ágeis (Visão do Projeto, Product Backlog e Ata de Sprint Planning).
*   **`02_Modelagem_UML/`**
    *   Contém o arquivo fonte do Astah (`.asta`) com a modelagem do sistema, juntamente com as exportações em imagem (PNG) dos Casos de Uso, Diagrama de Sequência e Diagrama de Classes.
*   **`03_Codigo_Gerado/`**
    *   Contém os *stubs* (esqueletos) de código-fonte em C# gerados automaticamente via Engenharia Direta a partir do Diagrama de Classes. Servem como prova estrutural da modelagem orientada a objetos.
*   **`.planning/`**
    *   Pasta gerada via framework GSD (Get Shit Done), contendo a organização avançada do roadmap, matriz de requisitos e contexto do sistema para orquestração de desenvolvimento.

## Metodologia Aplicada
- Framework Ágil (Scrum adaptado)
- Modelagem UML
- Orientação a Objetos
- Acessibilidade Shift-Left (WAI-ARIA)
- Segurança By Design (HttpOnly Cookies, BCrypt)
